# Codex 侧栏会话定位设计

- 日期：2026-07-23
- 状态：已实施
- 平台：当前 Mac（macOS 26.5.1）

## 目标

点击悬浮监控器中的任务后：

1. Codex 打开并切换到对应会话；
2. Codex 左侧会话菜单滚动到该会话，使其可见并保持选中状态。

## 已验证边界

- Codex 官方本机深链是 `codex://threads/<thread-id>`，现有代码已经使用它。
- 深链会恢复、显示并聚焦 Codex 窗口，然后导航到 `/local/<thread-id>`。
- 当前 Codex 没有公开“在侧栏中定位”的深链参数或 CLI 参数。
- Codex 侧栏 DOM 含会话 UUID，但 macOS 辅助功能树不暴露该字段、URL 或稳定 ID。
- `~/.codex/session_index.jsonl` 提供 UUID 到当前侧栏标题的追加式映射；同一 UUID 必须取最后一条完整记录。
- `~/.codex/.codex-global-state.json` 提供置顶、项目和项目外分组，可把标题匹配限制在正确侧栏列表。
- 不使用 Codex 私有 IPC、数据库写入或页面脚本注入。

## 最小方案

保留现有深链。深链成功后，使用 macOS 原生辅助功能 API：

1. 首次需要时请求“辅助功能”权限；未授权则保留正常深链跳转并显示明确提示。
2. 按 UUID 从 `session_index.jsonl` 读取最后一个完整标题；索引没有该 UUID 时拒绝侧栏定位，不使用数据库旧标题猜测。
3. 按 UUID 从全局状态解析置顶、项目或项目外分组；缺少显式 assignment 时，只接受任务 `cwd` 与唯一项目根路径完全相等的分组回退。
4. 仅当对应分组内恰好有一个精确同名元素时，执行 macOS 26 原生 `NSAccessibilityScrollToVisibleAction`；重名时拒绝滚动，不模拟点击。
5. Codex 界面异步加载时进行有限次数重试；新点击会使旧重试失效，超时后提示失败。

实现留在现有 Swift/AppKit 结构中，不引入第三方依赖或新后台进程。

## 验证

- 自动检查深链 UUID、追加索引的最后记录、截断尾行、分组解析和重名拒绝。
- 只读探针确认侧栏任务元素支持 `AXScrollToVisible`，并验证置顶、项目、项目外三类 AX 列表描述。
- 实机验收项目内任务和项目外任务：两者点击前侧栏行高度均为 `0`，点击后正文切换，侧栏行滚动到可见区域并恢复为 `17` 高度。

## 不做

- 不修改或重签 Codex。
- 不自动点击侧栏任务。
- 不请求屏幕录制权限。
- 不保留私有 UI 结构的兼容层。
- 不在同一分组存在重名时按顺序猜测目标。
