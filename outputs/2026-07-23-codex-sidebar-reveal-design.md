# Codex 侧栏会话定位设计

- 日期：2026-07-23
- 状态：已确认，待实施
- 平台：当前 Mac（macOS 26.5.1）

## 目标

点击悬浮监控器中的任务后：

1. Codex 打开并切换到对应会话；
2. Codex 左侧会话菜单滚动到该会话，使其可见并保持选中状态。

## 已验证边界

- Codex 官方本机深链是 `codex://threads/<thread-id>`，现有代码已经使用它。
- 深链会恢复、显示并聚焦 Codex 窗口，然后导航到 `/local/<thread-id>`。
- 当前 Codex 没有公开“在侧栏中定位”的深链参数或 CLI 参数。
- 不使用 Codex 私有 IPC、数据库写入或页面脚本注入。

## 最小方案

保留现有深链。深链成功后，使用 macOS 原生辅助功能 API：

1. 首次需要时请求“辅助功能”权限；未授权则保留正常深链跳转并显示明确提示。
2. 在 Codex 的辅助功能树中按会话 URL 的 UUID 定位对应侧栏元素，不按标题匹配，避免同名会话跳错。
3. 对目标元素执行 macOS 26 原生 `NSAccessibilityScrollToVisibleAction`，只滚动，不模拟点击。
4. Codex 界面异步加载时进行有限次数重试；超时后提示失败，不无限轮询。

实现留在现有 Swift/AppKit 结构中，不引入第三方依赖或新后台进程。

## 验证

- 先用只读辅助功能探针确认 Codex 暴露的目标元素包含可核对 UUID 的 URL，并支持滚动到可见动作；探针失败则停止，不退回标题猜测。
- 自动检查 URL 与 UUID 的精确匹配，确保不会定位同名或相邻会话。
- 实机验收：选一个不在当前侧栏可见区域的任务，点击监控器后确认正文切换、Codex 获得焦点、侧栏滚动并选中正确任务。

## 不做

- 不修改或重签 Codex。
- 不自动点击侧栏任务。
- 不请求屏幕录制权限。
- 不保留私有 UI 结构的兼容层。
